# cayley-transform

The Möbius map w = (z - i)/(z + i) appears as the Smith chart, Tustin's bilinear transform,
Crank-Nicolson stepping, the quadrature-to-sideband change of basis and more. These scripts check
the claims of a note collecting those appearances and explaining what they share.

- `scripts/verify_cayley.py`: 30 numerical checks (output in `.out`)
- `scripts/figure_cayley.py`: Figure 1 (`figures/`)
- `scripts/B-checks.py`, `scripts/agentC/`: further spot checks
- `cayley.pdf`: the note
